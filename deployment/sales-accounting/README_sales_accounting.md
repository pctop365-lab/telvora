# Учёт продаж TELVORA

Таблица: https://docs.google.com/spreadsheets/d/1VeN_Ibdp_eHXuo3yBzzzAYUARRhvU6IZjtshRyVpBPw/edit

## Что заполнится

- «Продажи»: номер, дата и статус заказа, клиент, контакты, товары, услуги, сумма и расчёт после оценки УСН 6%.
- «Позиции»: каждый товар, поставщик, артикул, закупочная цена из **снимка на момент заказа** и источник цены.
- Вручную вводятся: «Позиции» H (поставщик, если фактический иной), L (фактическая закупка за штуку), R (дата закупки), S (номер заказа поставщику); «Продажи» P:R (фактические расходы). Синхронизация эти значения сохраняет.
- Для старых заказов исторической закупочной цены в базе нет. Поле «Источник закупки» покажет «Нужна проверка закупки», а прибыль останется пустой до ввода закупки вручную. Дата выполнения старых заказов также остаётся пустой, если её не фиксировали ранее.

## Установка в правильном порядке

1. Сделайте резервную копию базы и текущих `api.php`, `manager.php` на сервере.
2. Выполните `sales_accounting_migration.sql` в базе магазина (например, через phpMyAdmin). Если в `orders` уже есть `completed_at`, выполните только создание таблицы снимков.
3. В приватный PHP-файл секретов, путь к которому возвращает `telvoraSecretsFile()`, добавьте `'sales_export_token' => '...'`. Сгенерируйте значение на сервере командой `php -r 'echo bin2hex(random_bytes(32)), PHP_EOL;'`. Секрет должен остаться вне публичной папки и не попадать в Git или переписку.
4. Поместите изменённые `api.php` и `manager.php`, новый `sales_export.php` в корень сайта рядом с `runtime_config.php`. Если деплой идёт через репозиторий, сначала добавьте эти три PHP-файла в корень проекта и пройдите обычный защищённый деплой. SQL-файл и файл с секретами на публичный сайт не копируйте.
5. Откройте указанную Google таблицу → **Расширения → Apps Script**. Вставьте всё содержимое `sales_sheet_sync.gs` в `Code.gs`, сохраните. В **Настройки проекта → Свойства скрипта** задайте:
   - `EXPORT_URL` = `https://telvora.ru/sales_export.php`
   - `EXPORT_TOKEN` = тот же секрет из шага 3.
6. В редакторе Apps Script выполните `syncSales`, разрешите доступ и проверьте несколько заказов. Затем один раз выполните `installSalesSyncTrigger` — он поставит запуск каждые 5 минут и заменит старый триггер этой функции, если он был.

## Проверки

- Запрос к `https://telvora.ru/sales_export.php` **без** заголовка токена должен вернуть HTTP 404; не вставляйте секрет в URL.
- Новый тестовый заказ: в «Позиции» появится поставщик, цена и «Снимок при заказе», а повторный запуск `syncSales` не создаст дубликат.
- После перевода заказа в «Выполнен» появится дата выполнения и расчёт после налога, если у всех товаров известна закупка.
- После ручного заполнения «Позиции» L/R/S и «Продажи» P:R повторный запуск не должен стереть их.

Даты из MySQL трактуются как время Москвы (+03:00); часовой пояс таблицы — Europe/Moscow. Оценка УСН — 6% от полной суммы заказа, не бухгалтерский расчёт реального налога.
