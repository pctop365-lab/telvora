TELVORA — подготовка к размещению

Это исходный проект Bolt, очищенный от node_modules и разложенный в корне проекта.

ВАЖНО:
1) Это НЕ production-сборка. В присланном архиве не было пригодных к запуску локальных зависимостей Vite, поэтому dist/ здесь не создавался.
2) Для обычного Host-0 нужно сначала выполнить `npm install`, затем `npm run build`.
3) На хостинг загружается содержимое папки `dist/`, а не src/ и не весь исходный проект.
4) Файл .htaccess уже добавлен для React Router на Apache-подобном хостинге.

Команды:
npm install
npm run build

После успешной сборки:
загрузить содержимое dist/ в www/telvora.ru/

Не удаляйте старый сайт, пока новая сборка не будет проверена.
